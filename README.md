# **Brapi - API da Bolsa de Valores**

A **Brapi** oferece uma API robusta para consultar dados em tempo real da Bolsa de Valores, incluindo cotações, ações, índices e volume de negociação. Ideal para desenvolvedores, investidores e analistas, a **Brapi** permite integrar informações financeiras confiáveis em suas aplicações de forma simples e eficiente.

## **Funcionalidades**

- **Consulta de Cotações:** Obtenha as cotações mais recentes das ações.
- **Índices Financeiros:** Acesse os índices de mercado em tempo real.
- **Volume de Negociação:** Verifique o volume de transações realizadas.
- **Consultas Personalizadas:** Realize buscas de dados de acordo com filtros específicos, como data, ações ou categorias.
